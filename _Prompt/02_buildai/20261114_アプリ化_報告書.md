## 4. らいおが見る手順（5 手）

1. `C:\_Prog\ECU\Logger\MBD2MES\dist\mbd2mes.exe` をダブルクリックする。窓の標題が `MBD2MES v0.2.0 …`、タスクバーにアイコンが出る
2. Convert タブの Output Directory の「Change...」で 2D の出力先（イベントフォルダ）を選び、「Browse Files...」で `.MBD`（標本のコピー）を選ぶ
3. 「Convert」を押す。ログに `Invariant check: PASS` が出て、完了の窓に `Converted 1 of 1 file(s).` が出る
4. Channel Map タブで、例えば `THP` をダブルクリックして Custom Name（例 `Throttle`）や Unit・Multiplier・Offset を入れて OK → 「Save」→ もう一度 Convert（同名の MES の上書き確認は Yes）
5. 2D Analyzer で出力した `.MES` を開き、地図の軌跡・ラップ・編集したチャンネルの名前と値を見る（Custom Name は元のチャンネルを残して別名を**足す**。Latitude・Longitude・V_GPS は固定）

## 7. アイコンを確かめた方法

親の指示（`Pic\ICON\MBD2MES.ico` を正本にし、exe のアイコン・窓・同梱へ。無ければビルドを止める）に従った。

- **exe に埋まったアイコン = ICO**: `tools\exe_icon.py`。exe を**実行せず** `LoadLibraryExW(LOAD_LIBRARY_AS_DATAFILE)` で開き、`RT_GROUP_ICON` の項目（寸法・bit 数）と各 `RT_ICON` の画像のバイト列を取り、ICO の項目と **(幅, 高さ, bit 数, 画像の SHA-256) の集合**で突き合わせる。結果 `PASS match: 7 sizes [16, 24, 32, 48, 64, 128, 256]`（ビルドの最後で毎回、かつ `tests/test_exe.py::test_exe_embedded_icon_equals_the_ico`）。道具が「必ず一致」を返さないことは `test_exe_icon_compare_detects_a_different_icon`（python.exe のアイコンは不一致になる）で確かめた
- **ICO 自体**: `test_ico_has_the_seven_sizes`（7 段・寸法の集合が依頼どおり。リポ直下に `ICON\` が無い）
- **GUI が起動時にアイコンを読み込める**: `test_gui_builds_and_loads_the_icon_at_startup`（窓を出さない `withdraw` の Tk で `iconbitmap(default=...)` が通り True を返す）・読めないときも起動は続く `test_gui_icon_failure_does_not_stop_startup`
- **窓の確認（未実施）**: `tests/gui/exe_window_probe.py`（exe を別名で一時フォルダへ写して起動し、その子プロセスの窓の標題と `WM_GETICON`（大・小）を読み、プロセス木を止めて 0 本を数える）を away-gate の行列 `j0359`（desktop・3 分）に載せた。利用者が在席のため**離席待ち**。結果のログは `away-gate wait j0359` で読める。流れるまで「窓が出る」とは言わない
- 「spec が ICO 無しで止まること」は `test_spec_stops_when_icon_is_missing`、bat は `if not exist Pic\ICON\MBD2MES.ico` で止まる
