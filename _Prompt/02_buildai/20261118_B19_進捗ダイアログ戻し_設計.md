## 2. どう直すか

1. Skill の `templates/converter_progress/` を **手を入れずに** `mbd2mes/converter_progress/` へ写す。写した各ファイルの SHA-256 を `docs/provenance.md` に記録する（Skill が直ったとき、差し替えと照合が手早い）
2. `mbd2mes/progress.py` は MBD2MES 固有の部分だけを残す薄い形にする: 段の名前・重み（今の値のまま）で `CONFIG = ProgressConfig(...)` を作り、今の名前（`STEP_LABELS`・`STEP_COUNT`・`STEP_WEIGHTS`・`file_fraction`・`overall`・`make_event`・`ProgressEvent`）を CONFIG に結んで出す。convert.py・app_convert.py・道具・既存の試験は書き換えずに動く
3. `mbd2mes/jobs.py`・`progress_dialog.py`・`busy_animation.py` は消し、使う側（gui.py・道具・試験）の import を `mbd2mes.converter_progress` へ替える。GIF の基準フォルダは今と同じ `Pic/anim/busy.gif`（`GifLocation` で合わせる）
4. gui.py の終わり方を Skill の例（`gui_wiring_example.py`）に合わせる: 成功は `finish_then_close` で Done を見せてから閉じ、ボタンを戻して結果を出す。Done を省くのは実際に止めた結果（Cancelled・止めたファイルあり）のときだけ
5. メイン窓の ×: ダイアログがあれば前に出して案内する（閉じない。今と同じ）。ダイアログが出せなかったときだけ「変換を止めますか」を聞き、Yes なら Cancel の旗を立てる
6. 版を v0.3.1 に上げ、exe を作り直す。Cancel しない変換の MES が v0.3.0 とバイト単位で同じことを確かめる

## 3. 試験

- Skill の試験 5 本と conftest を `tests/converter_progress/` へ写す（`PACKAGE = "mbd2mes.converter_progress"`）
- 既存の試験（`test_cancel.py`・`test_gui_progress.py`・`test_progress.py`・`test_progress_dialog.py` ほか）は全部通す。ダイアログの試験は写した Skill の試験と重なる所を整理してよいが、Cancel と公開の試験は消さない
- 足す試験: 成功で Done が見えてから閉じる（閉じる時刻の下限）・Cancel では待たない・ダイアログが出せないときの × の確認
- 新しい試験は、直す前のコードで落ちることを確かめる
- 窓は画面に出さない（画面に出る確認は away-gate の列に並べる）

数字の札:

| 数字 | 何の数字 | 札 | 根拠／見直しの合図 |
|---|---|---|---|
| 1 秒 | ダイアログを出しておく最短の時間（MIN_SHOW_S） | 根拠 | RCZ2MES・LD2MES の exe でらいおが確かめた値 |
| 0.5 秒 | Done を見せる時間（DONE_HOLD_S） | 仮置き | らいおが短い・長いと言ったとき |
| 5 秒 | ワーカーの終わりを待つ上限 | 仮置き | 実機でこの上限を超えたとき |
