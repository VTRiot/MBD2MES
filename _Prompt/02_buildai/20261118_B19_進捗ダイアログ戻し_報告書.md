- **外したもの（未実施・窓が出るため）**: `tests/test_exe.py`（exe を起動する）・`tests/gui/exe_window_probe.py`（exe の窓の探り）・`tools/render_dialog_snapshot.py`（撮影）。`test_release.py` の exe 必要の 2 件
- Skill の試験 5 本の写し: 97 passed。ダイアログの試験は親を withdraw したまま（既存の作法どおり）
- 足した試験（`tests/test_finish_and_close.py` 8 本）:
  1. 速い成功でも Done が見えてから閉じる・開いてから MIN_SHOW_S 以上出ている（閉じる時刻の下限）
  2. Cancel は待たずに閉じる（`min_show_s = 0`・Done にならない）
  3. 公開の直前に旗が立ったが変換は成功した、ときは Done（旗の有無でなく実際の結果で決める）
  4. ダイアログ無しで ×: 確認を出し、Yes で旗が立ち実際に止まる
  5. ダイアログ無しで ×: No なら旗は立たず変換は成功する
  6. ダイアログ有りで ×: 確認も案内の窓も出さず、前に出してログに書くだけ
  7. Done の保持中の ×: Cancel の案内も別の窓も出さず、閉じもしない
  8. 確認を開いている間に変換が終わっても、Yes で終わった仕事の旗を立てない

## 4. MES のバイト比較

- 方法: 変更前に、サンプルのコピー（SHA-256 一致を Python で OK 判定）を `python -m mbd2mes <サンプル> -o <一時置き場>` で変換し、出た MES フォルダの全ファイルの SHA-256 を控えた（63 ファイル）。設定フォルダは変換のたびに新しい物（`MBD2MES_SETTINGS_DIR`）にした。変更前に 2 回回して 2 回とも一致（時刻を含むファイルは無い）
- 変更後（CLI）・変更後（進捗の通知と Cancel 用の旗を付けた `app_convert.convert_many`・GUI と同じ経路）・最終のコードで再度 CLI: いずれも **63 ファイルすべて・差分 0 でバイト一致（判定 BYTE-IDENTICAL）**。時刻を含むために違うファイルは無かった
