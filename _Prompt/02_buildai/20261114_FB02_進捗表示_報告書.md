## 用語集

| 語 | 意味 |
|---|---|
| 段（step） | 変換 1 本を 7 つに分けた区切り。`Step 3/7` の 3 |
| 重み | その段が変換全体の何割の時間か。全体の % を出す係数（標本の実測の比） |
| GIL | Python が 1 度に 1 つのスレッドしか Python の処理を進めさせない仕組み。変換スレッドが握り続けると画面が動けない |
| 不定のバー（indeterminate） | % ではなく、動いていることだけを見せる左右に動くバー |
| 整数倍 | PhotoImage の `zoom`・`subsample` は整数倍しかできないので、約 1.5 cm に最も近くなる倍率を選ぶ |
