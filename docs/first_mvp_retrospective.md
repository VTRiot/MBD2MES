# 最初の動く版の後の振り返り

## 本書の読者と目的

- 読者: このプロジェクトの CC
- 目的: プロジェクトの立ち上げ時に用意した CLAUDE.md と docs が、最初の動く版を作るまでに役立ったかを振り返り、次に同じ型のプロジェクトを立ち上げるときの質を上げる
- 本書は起動時には読み込まれない。CLAUDE.md の「最初の動く版の後」の 1 行から読む

## きっかけと回数

- きっかけ: らいおが最初の変換結果を 2D Analyzer で開いて、見られたと言ったとき
- 回数: 1 回だけ。済んだら CLAUDE.md の該当の行を「済み（日付・報告書のパス）」に書き換える

## 問い

立ち上げ時の CLAUDE.md・CLAUDE.local.md・docs（`mes_format*.md`・`lessons_*.md`）について、次の 3 つを具体的に挙げる。それぞれ「何で困り、何に時間を使ったか」を添える。

1. あれば早かった情報（無くて自分で調べた・らいおに聞いた・遠回りした）
2. 間違っていた・古かった情報（どの記述が、実物の何と食い違ったか。出典つき）
3. 読んだが使わなかった情報（削ってよい候補）

## 出口（結果の置き場）

| 中身 | 置き場 |
|---|---|
| 2D・MES の形式の新しい知見 | 2D 知見ハブ（パスは CLAUDE.local.md）。確度（実測・推定・未検証）を付けて 1〜3 行 |
| 立ち上げの手順や用意する資料の不足 | skill `logger-to-2d-mes-project-setup` の更新提案。skill の提案の手順（skill-proposal-emitter）で出す |
| このプロジェクト固有の話 | このプロジェクトの docs |

結果は `_Prompt\02_buildai\` の報告書にまとめ、らいおへ 1 段落で伝える。
