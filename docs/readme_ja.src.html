MBD2MES

説明している版: {{VERSION}}

MBD2MES は、HRC の車両ロガー MBDA2 が書き出す .MBD ファイルを、2D Analyzer で開ける .MES フォルダに変換するソフトです。チャンネルのデータと、GPS の軌跡（2D の地図）が .MES に入ります。

必要なもの

  • Windows 11（Windows 10 でも動くはずですが、確かめていません）。
  • mbd2mes.exe が 1 個。インストーラーはなく、Python も要りません。
  • MBDA2 が書き出した .MBD と、結果を開くための 2D Analyzer。

最初の変換

  1. mbd2mes.exe を、好きなフォルダ（例: C:\MBD2MES）に置きます。設定ファイルもこの exe の隣に作られるので、書き込める場所に置いてください。ZIP の中から直接動かさないでください。
  2. mbd2mes.exe をダブルクリックします。画面が開き、タイトルバーに版の名前が出ます（{{VERSION}} を含みます）。
  3. 知らないプログラムとして Windows の警告が出ることがあります（この exe には署名がありません）。出どころが信頼できるなら、実行を選べます。
  4. Convert タブの Browse Files... を押して .MBD を選びます（複数選べます）。
  5. Output Directory を確かめます。2D のイベントフォルダでなければ Change... で選びます。
  6. Convert を押します。変換中は進捗のダイアログが出ます。終わるとダイアログが自動で閉じ、結果が Log に出ます。
  7. できた .MES フォルダを 2D Analyzer で開きます。

変換の結果は、出力先の中の、入力ファイルと同じ名前の .MES フォルダに作られます（例: sample.MBD から sample.MES）。同じ名前の .MES が既にあるときは、変換が成功したときだけ入れ替わります。失敗したときは、前の .MES はそのまま残ります。

Channel Map（名前・単位・一次変換）

Channel Map タブで、チャンネルごとに、2D に出る名前・単位・一次変換（値 × 倍率 + オフセット）を決められます。Convert で新しいチャンネルに出会うと、一覧に自動で追加されます。

項目意味
MBD NameMBD に入っているチャンネルの名前（読み取り専用）
Unit2D に出る単位。Passthrough MBD unit にチェックすると、MBD の単位をそのまま使います
Custom Name2D に出す名前。空なら MBD の名前を使います
Multiplier / Offset一次変換。2D に出る値 = MBD の値 × Multiplier + Offset
  • 行を選んで Edit... で編集します。Filter: で行を絞り込めます。
  • Reset Row to Default は 1 行を初期値へ、Delete Row は 1 行の削除、Reset Entire Map は全体を初期値へ戻します。
  • 変更は Save を押すまで保存されません。

Convert Unconverted（まだ変換していない物を一度に）

前に Browse Files... で選んだ .MBD のフォルダを調べ、まだ変換していない物をまとめて変換します。調べる → 確認の画面（一覧）→ 変換、の順です。

  • 最初の 1 回は何も変換せず、そのフォルダの「起点」だけを記録します。次回から、その時刻より後に届いた・変わった .MBD だけが対象になります。
  • 既にあるファイルも変換したいときは、Convert all .MBD files にチェックを入れて押すか、Convert で選びます。チェックは、実行の後に自動でオフへ戻ります。
  • 変換した物は、出力先の台帳（.mbd2mes_manifest.json）に記録されます。外から出力先が変えられていたファイルは、上書きしません。

Use This（イベントフォルダの候補）

2D WinRace で今選んでいるイベントフォルダが分かるときは、Detected candidate として候補が出ます。Use This を押すと、それを出力先にします。候補が変わったら Reload で読み直します。見つからないときは Not detected と出て、Use This は押せません（そのときは Change... で選んでください）。

日付の決まり方

.MBD の中に記録の日付は入っていません。そこで、2D の HED に書く日付は次の順で決めます（上が優先）。

  1. Recording Date (HED) の欄に YYYY-MM-DD と書いたとき、それを全部の入力に使います。
  2. 空なら、ファイル名から読みます。対応する書き方: 2026-11-08・2026.11.08・26.11.8・20261108 など（年は 2000〜2099）。
  3. どちらでもなければ、ファイルの更新時刻を使います。このときは、確認の画面とログに警告が出ます。ダウンロードやコピーをした日など、レースの日と違うことがあるので、日付の欄に書くか、ファイル名に日付を入れてください。

変換中のダイアログと Cancel

  • 上に、何本中の何本目か（File k/n）、ファイル名、段（Step k/7）が出ます。真ん中が % のバー、その下が経過時間と残りの目安です。残りの目安は、始めの数秒は calculating... と出ます。
  • 変換の間、右の絵が動きます。ダイアログが開いている間、親の画面は操作できません。
  • Cancel（または右上の × ・Esc キー）で、なるべく早く止まります。止まるまで少しかかります（Cancelling... と出ます）。
  • 止めても、作りかけの .MES は残らず、既にあった .MES は変わりません。止めたファイルは「変換済み」と記録されないので、Convert Unconverted でもう一度対象になります。
  • 複数本のとき、Cancel で残りはやめます。終わったファイルは変換済みのままです。どこまで終わったかは Log に出ます。
  • 出力先へ入れ替えている最中（ごく短い間）は止めず、入れ替えが終わってから止まります。そのときはログにそう出ます。
  • 変換中に、メインの窓の × で閉じることはできません（案内が出ます）。先に Cancel するか、終わるのを待ってください。

設定の置き場所

設定と対応表は、mbd2mes.exe の隣の次のファイルに保存されます。

ファイル中身
mbd2mes_config.json出力先・最後に選んだ .MBD のフォルダ・フォルダごとの起点
channel_map.jsonChannel Map（名前・単位・一次変換）

exe のフォルダに書けないときは、%LOCALAPPDATA%\MBD2MES\ に作られます。設定の場所は、Other タブの Settings folder に出ます。

版を上げるとき

  1. MBD2MES を閉じます（動いている間は mbd2mes.exe を置き換えられません）。
  2. 新しい mbd2mes.exe を、今の mbd2mes.exe に上書きでコピーします。配布の ZIP に設定ファイルは入っていないので、exe の隣の設定と対応表はそのまま使われます。
  3. 起動して、タイトルバーまたは Other タブの版の名前を確かめます。

念のため、上書きする前に、exe の隣の mbd2mes_config.json と channel_map.json を別の場所へ控えておくと安心です。
